# Configuration reference

_The key table is generated by `tools/Update-Docs.ps1` from the schema in `aic.ps1`._

Two optional JSON files hold defaults: `~/.aic.json` (personal, every repo) and `<repo>/.aic.json` (wins over the personal file). A flag you type wins over both. `aic -Init` writes a starter file; `aic -ConfigValidate` checks both files without contacting any server (exit 0 = valid, 1 = problems).

Every key is validated. Unknown keys get a "did you mean" hint, wrong types and invalid values are reported and ignored, out-of-range numbers are clamped and reported. A repo list (`scopes`, `exclude`, `aiFiles`) replaces the personal one only for keys it sets; lists are not merged.

| Key | Type | Values | Description |
|---|---|---|---|
| `model` | text |  | Ollama / server model name. |
| `language` | text |  | Language of the subject and bullets (type and scope stay English). |
| `coAuthor` | text |  | Adds a "Co-authored-by: ..." footer to every commit. |
| `bullets` | whole number | 0 to 6 | Maximum body bullets (0 = subject line only). |
| `history` | whole number | 0 to 20 | How many recent commit subjects the model sees as a style reference. |
| `width` | whole number | 50 to 140 | Maximum card width. |
| `provider` | text | ollama, openai-compatible | Which kind of server to talk to. |
| `profile` | text | fast, balanced, quality | Model profile, used only when no "model" is configured. An explicitly typed -Model always wins. |
| `emoji` | true / false |  | Gitmoji after the colon. |
| `autoStageAi` | true / false |  | Every run behaves like -AiFiles. |
| `lint` | true / false |  | Built-in leftover / conflict-marker / large-file checks. |
| `autoRef` | true / false |  | Derive a "Refs:" footer from the branch name. |
| `exclude` | list of text |  | Extra pathspecs hidden from the MODEL (they are still scanned for secrets and still committed). |
| `scopes` | list of text |  | Allowed commit scopes (case-sensitive). Also used to pick scopes with the s key. |
| `aiFiles` | list of text |  | Extra globs that count as AI-related files. |
| `theme` | text | ocean, sunset, forest, neon, mono, aurora, rose, gold, dracula, candy | Colour theme. |
| `spinner` | text | dots, arc, bounce, pulse, grow, line, star, orbit | Spinner animation. |
| `border` | text | rounded, square, double, heavy | Card border style. |
| `banner` | text | mini, big, none | Header style. |

## Example

```json
{
  "model": "qwen2.5-coder:7b",
  "language": "English",
  "bullets": 3,
  "scopes": ["api", "ui", "docs"],
  "exclude": ["*.svg"],
  "aiFiles": ["prompts/*", "*.prompt.md"],
  "lint": true,
  "autoRef": true
}
```

## Environment variables

| Variable | Effect |
|---|---|
| `OLLAMA_HOST` | Server address for the Ollama provider (`:11434`, `host:port`, `0.0.0.0:11434` are accepted). |
| `AIC_API_KEY` | Optional Bearer token sent to the server (any provider). Read from the environment only; never printed, logged or written to a config file. |
| `NO_COLOR` | Disables colour. |
