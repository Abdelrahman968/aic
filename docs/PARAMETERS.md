# Parameter reference

_Generated by `tools/Update-Docs.ps1` from the parameter block and comment-based help of `aic.ps1`: do not edit by hand. `Get-Help aic -Full` shows the same text._

aic has 70 parameters. Settings precedence: flag you type > $PSDefaultParameterValues > .aic.json in the repo > ~/.aic.json > built-in default.

| Parameter | Type | Default | Constraints | Description |
|---|---|---|---|---|
| `-Model` | String | `'qwen2.5-coder:7b'` |  | Ollama model. Tab-completes with the models you have installed. |
| `-OllamaUrl` | String |  |  | Server URL (for either provider). Default: $env:OLLAMA_HOST, else http://localhost:11434 (openai-compatible: http://localhost:1234). |
| `-MaxChars` | Int32 | `6000` |  | Diff size cap, shared fairly between files (small files free budget for big ones). |
| `-NumCtx` | Int32 | `4096` |  | Context window; auto-raised when the prompt needs more. |
| `-NumPredict` | Int32 | `256` |  | Max tokens in the answer. |
| `-Temperature` | Double | `0.2` | range 0.0..2.0 | Sampling temperature (rises a little on every retry for variety). |
| `-KeepAlive` | String | `'10m'` |  | How long Ollama keeps the model in memory, e.g. 10m. |
| `-TimeoutSec` | Int32 | `180` |  | Whole-generation timeout (first call includes model load). |
| `-StartOllama` | switch |  |  | Start `ollama serve` automatically if the server is not running (otherwise it asks). |
| `-Unload` | switch |  |  | Unload the model from (V)RAM when aic finishes. |
| `-Type` | String |  | one of: feat, fix, refactor, perf, docs, style, test, build, ci, chore, revert | Force the commit type. |
| `-Scope` | String |  |  | Force the scope. |
| `-Breaking` | switch |  |  | Mark as a breaking change: type(scope)!: |
| `-Emoji` | switch |  |  | Gitmoji after the colon, e.g. "feat: <sparkles> add login". Toggle live with the x key. |
| `-Hint` | String |  |  | Extra context for the model. |
| `-Language` | String | `'English'` |  | Language of subject + bullets (type and scope stay English). |
| `-Bullets` | Int32 | `3` | range 0..6 | Max body bullets (0 = subject line only). |
| `-History` | Int32 | `3` | range 0..20 | How many recent commit subjects the model sees as a style reference (0 = none). |
| `-Ref` | String |  |  | Footer reference, e.g. -Ref '#42' adds "Refs: #42". |
| `-Exclude` | String[] |  |  | Extra pathspecs hidden from the model, e.g. '*.svg'. |
| `-Retries` | Int32 | `1` | range 0..5 | Automatic retries when the format check fails. |
| `-Variants` | Int32 | `3` | range 2..6 | How many alternatives the v key generates (2-6). |
| `-NoScan` | switch |  |  | Skip the secrets / sensitive-file warning. |
| `-All` | switch |  |  | git add -A first. |
| `-AiFiles` | switch |  |  | git add every changed AI-related file first (works together with other staged files and with -Pick). |
| `-AiOnly` | switch |  |  | Make this commit hold ONLY AI-related files: stages them and unstages everything else (working tree untouched). |
| `-AiPattern` | String[] |  |  | Extra globs that count as AI-related, e.g. 'agents/*','*.skill.md'. |
| `-ListAi` | switch |  |  | List the changed AI-related files (and whether they are staged), then exit. |
| `-Pick` | switch |  |  | Show the file checklist even when something is already staged. |
| `-Amend` | switch |  |  | Rewrite the message of the last commit. |
| `-Push` | switch |  |  | Push after committing (sets upstream on a new branch). |
| `-NoVerify` | switch |  |  | Skip git hooks. |
| `-Signoff` | switch |  |  | Add Signed-off-by. |
| `-Undo` | switch |  |  | Soft-undo the last commit and exit. |
| `-Init` | switch |  |  | Create a starter .aic.json in the repo root and exit. |
| `-Doctor` | switch |  |  | Run a health check and exit. |
| `-Log` | Int32 | `0` | range 0..100 | Show the last N commits as coloured type pills and exit. |
| `-ListThemes` | switch |  |  | Preview every theme and exit. |
| `-Review` | switch |  |  | Ask the local model to review the staged diff (bugs, risks, leftovers), print the notes and exit. Advisory only. |
| `-Pr` | switch |  |  | Write a pull-request title + markdown description from the commits and diff of the current branch. |
| `-Into` | String |  |  | Target branch for -Pr (default: origin's default branch, else main / master / develop). |
| `-Changelog` | switch |  |  | Print a changelog grouped by commit type (breaking changes first). With -Copy it also goes to the clipboard. |
| `-Since` | String |  |  | Starting ref for -Changelog (default: the latest tag, else the whole history). |
| `-Bump` | switch |  |  | Suggest the next semantic version from the commits since the last tag and offer to create the annotated tag. |
| `-Stats` | switch |  |  | Commit statistics: sparkline, streak, busiest day, top types and scopes. |
| `-Days` | Int32 | `30` | range 1..365 | Window for -Stats, 1-365 (default 30). Above 42 days the sparkline switches to weekly bars. |
| `-NewBranch` | switch |  |  | Let the model name a branch for the staged changes (type/short-description), create it after you confirm, then continue with the normal commit flow. |
| `-CoAuthor` | String |  |  | Add a "Co-authored-by: Name <email>" footer. |
| `-NoLint` | switch |  |  | Skip the built-in leftover / conflict-marker / large-file checks. |
| `-NoAutoRef` | switch |  |  | Do not derive a "Refs:" footer from the branch name. |
| `-ConfigValidate` | switch |  |  | Check ~/.aic.json and the repo's .aic.json (unknown keys, wrong types, bad values) and exit. Needs no Ollama. Exit code 0 = valid, 1 = problems found. |
| `-Provider` | String | `'ollama'` | one of: ollama, openai-compatible | ollama (default) \| openai-compatible (LM Studio, llama.cpp server or any OpenAI-style /v1 endpoint). | `-ModelProfile` | String |  | one of: fast, balanced, quality; alias: -Profile | fast \| balanced \| quality (alias -Profile): pick the installed model that fits (small / about 7B / the largest practical one). An explicit -Model wins. |

| `-ReviewMarkdown` | switch |  |  | Like -Review, but emit a Markdown report on the pipeline (interface on stderr). Cannot be combined with -ReviewJson. |

| `-ReviewDiff` | String |  |  | Review the diff between a ref and HEAD (for example -ReviewDiff main) instead of the staged changes. Never touches the index. |
| `-Yes` | switch |  |  | Skip the review prompt and commit (refuses when the format check or secret scan complains). |
| `-DryRun` | switch |  |  | Show the message, commit nothing. |
| `-Copy` | switch |  |  | Copy the message to the clipboard, commit nothing. |
| `-PassThru` | switch |  |  | Also return the final message as a string. |
| `-Theme` | String | `'ocean'` | one of: ocean, sunset, forest, neon, mono, aurora, rose, gold, dracula, candy | ocean \| sunset \| forest \| neon \| mono \| aurora \| rose \| gold \| dracula \| candy |
